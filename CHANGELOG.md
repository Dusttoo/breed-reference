# Changelog

## 1.0.0 — 2026-10-13

- Published the initial species-neutral catalog.
- Added 439 dog breed records audited against six registry indexes.
- Added 71 cat breed records audited against three registry indexes, with GCCF
  as a supplementary coverage check.
- Added copy-friendly static text lists, JSON Schemas, validation, registry
  snapshot tooling, reconciliation tooling, and continuous integration.
